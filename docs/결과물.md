# 최종 결과물

> Automatic Temperature Control Fan  
> LTspice 기반 폐루프 자동 온도 제어 시스템 최종 결과 요약

---

## 1. 프로젝트 최종 목표

본 프로젝트의 최종 목표는 다음과 같다.

- NTC Thermistor로 열원 온도 감지
- 약 50℃ 부근에서 Fan ON
- 약 45℃ 부근에서 Fan OFF
- Comparator Hysteresis를 이용한 Chattering 방지
- NE555를 이용한 MOSFET Gate 구동 신호 생성
- NMOS Low-side Switching으로 Fan 구동
- Flyback Diode를 이용한 유도성 부하 보호
- Fan 동작 결과를 Thermal Model에 다시 반영하는 Closed-loop 구현

최종적으로 다음과 같은 시스템 구조를 완성하였다.

```text
Thermal Model
      ↓
NTC Thermistor
      ↓
Sensor Voltage
      ↓
LT1016 Comparator
      ↓
Hysteresis
      ↓
NE555
      ↓
NMOS
      ↓
5V Fan Model
      ↓
RPM / Cooling
      ↓
Thermal Model Feedback
```

---

## 2. 최종 회로 구성

| 구분 | 회로 요소 | 최종 값 / 모델 | 역할 |
|---|---|---|---|
| Temperature Sensor | R4 NTC | `R25=10kΩ`, `Beta=3950` | 온도에 따른 저항 변화 |
| Sensor Divider | R3 | 10kΩ | NTC 저항을 센서전압으로 변환 |
| Reference Divider | R6 | 10kΩ | 기준전압 생성 |
| Reference Divider | R9 | 3.9kΩ | 기준전압 생성 |
| Hysteresis | R5 | 68kΩ | ON/OFF 임계온도 분리 |
| Comparator | U3 | LT1016 | Sensor Voltage와 Reference 비교 |
| Pulse/PWM | U1 | NE555 | MOSFET Gate 구동 |
| Gate Resistor | R2 | 100Ω | Gate 충·방전 과도현상 완화 |
| Power Switch | M1 | `NMOS_FAN` | Fan Low-side Switching |
| Protection Diode | D3 | 1N5819 | Flyback Voltage 억제 |
| Fan Model | X_FAN | `FAN5V.lib` | Fan 부하 및 RPM 표시 신호 |
| Thermal Capacitance | C_TH | `Cth=0.5` | 열관성 모델링 |
| Heat Source | B_TH | Behavioral Source | 가열·자연방열·Fan Cooling 모델링 |

## 3. Thermal Model 설정값

최종 열 모델은 다음 파라미터를 사용하였다.

```spice
.param Tamb=25
.param Rth=5
.param Cth=0.5
.param Pheat=6
.param Pcool=15

C_TH TEMP_MON 0 {Cth} IC=40

B_TH 0 TEMP_MON I={
 Pheat
 -(V(TEMP_MON)-Tamb)/Rth
 -Pcool*if(V(RPM)>0.5,1,0)
}
```

본 프로젝트에서는

```text
TEMP_MON 1V = 1℃
```

로 대응시켰다.

따라서 `V(TEMP_MON)=48V`는
실제 전원전압 48V가 아니라 열 모델에서 **48℃를 의미하는 상태값**이다.

---

## 4. 최종 Hysteresis 설계값

최종 회로에서는

```text
R6 = 10kΩ
R9 = 3.9kΩ
R5 = 68kΩ
```

을 사용하였다.

R6와 R9가 기본 Reference Voltage를 만들고,
R5가 Comparator Output을 Reference Node로 Positive Feedback한다.

LT1016의 실제 Simulation Output 수준을 반영한 계산 결과
대략 다음 임계값을 얻었다.

| 항목 | 결과 |
|---|---:|
| Fan ON Temperature | 약 **49.3℃** |
| Fan OFF Temperature | 약 **45.5℃** |
| Hysteresis Width | 약 **3.8℃** |

즉 동작은 다음과 같다.

```text
Temperature 상승
        ↓
약 49.3℃
        ↓
Fan ON
        ↓
Cooling
        ↓
약 45.5℃
        ↓
Fan OFF
```

45~49℃ 사이에서는 Fan이 항상 ON 또는 OFF인 것이 아니라
이전 상태에 따라 상태를 유지한다.

---

## 5. 최종 Simulation 결과

최종 Transient Analysis는 다음 명령을 사용하였다.

```spice
.tran 0 60 0 10m startup
```

주요 파형 결과는 다음과 같다.

| 측정 대상 | 측정 노드 | 파형 범위 | 해석 |
|---|---|---:|---|
| Temperature | `V(temp_mon)` | 약 45~49V | 약 45~49℃ 반복 |
| Fan RPM 표시값 | `V(rpm)` | 약 0~10V | Fan OFF / ON 반복 |
| Comparator Output | `V(n003)` | 약 0~3.7V | 온도 상태 판단 |
| NE555 Output | `V(n005)` | 약 0~5V | Pulse/PWM 구동 신호 |
| MOSFET Gate | `V(n006)` | 약 0~5V | NMOS Gate Switching |

---

## 6. Temperature와 Fan 동작 관계

최종 파형에서 다음 Closed-loop 동작을 확인하였다.

```text
Fan OFF
→ Temperature 상승
→ 약 49.3℃ 도달
→ Comparator 상태 전환
→ NE555 출력 활성화
→ NMOS Switching
→ Fan ON
→ RPM 활성화
→ Cooling 적용
→ Temperature 하강
→ 약 45.5℃ 도달
→ Comparator 상태 반전
→ Fan OFF
→ 다시 Temperature 상승
```

이 과정이 반복되면서
열원 온도가 일정 범위 안에서 주기적으로 유지된다.

## 7. 각 블록별 최종 검증 결과

### 7.1 NTC Sensor

온도가 올라갈수록 NTC 저항이 감소하고
Voltage Divider 출력도 감소하는 것을 확인하였다.

```text
Temperature ↑
→ RNTC ↓
→ Vsensor ↓
```

---

### 7.2 LT1016 Comparator

`V(n003)`은 약 0~3.7V 범위에서 전환되었다.

Comparator의 출력 상태가
상한과 하한 임계온도에서 서로 다르게 바뀌는 것을 통해
Hysteresis가 정상적으로 동작함을 확인하였다.

---

### 7.3 NE555

`V(n005)`는 약 0~5V의 Pulse/PWM 형태로 나타났다.

Comparator가 Fan 구동을 허용한 구간에서
NE555 출력이 활성화되는 것을 확인하였다.

---

### 7.4 MOSFET Gate

`V(n006)`은 약 0~5V로 Switching되었다.

NE555 Output이 R2 100Ω을 거쳐
MOSFET Gate까지 정상적으로 전달되는 것을 확인하였다.

---

### 7.5 Fan Model

Fan Model은 다음 구조를 사용하였다.

```spice
.subckt FAN5V P N RPM
Rcoil P X 8
Lcoil X N 300u
Bspeed RPM 0 V={limit(V(P,N),0,5)*2.0}
Rrpm RPM 0 1Meg
.ends FAN5V
```

이 모델의 `V(RPM)`은 실제 Tachometer 측정값이 아니라
Fan 양단전압을 기반으로 만든 **RPM 표시용 신호**이다.

따라서 `V(RPM)=10V`는 실제 전원 노드 10V가 아니라
모델 내부에서 약 10,000rpm에 대응하도록 만든 표시값이다.

## 8. Power Stage 최종 구성

NMOS는 Low-side Switch로 사용하였다.

```text
5V
 │
Fan
 │
Drain
NMOS
Source
 │
GND
```

Gate가 약 5V일 때 MOSFET이 ON되고,
Gate가 0V일 때 OFF된다.

Gate에는 R2 100Ω을 사용하였고,
유도성 부하 보호를 위해 D3 1N5819 Flyback Diode를 추가하였다.

이를 통해 단순한 신호 제어뿐 아니라
**Power Semiconductor Switching + Inductive Load Protection**까지 포함하였다.

---

## 9. 최종 설계에서 해결한 주요 문제

프로젝트 과정에서 다음 문제를 해결하였다.

- 단일 Threshold에 의한 Chattering 가능성
- NTC Sensor를 온도가 아닌 저항값 관점으로만 보던 문제
- Comparator 기준전압 설정 방식의 불명확성
- LTspice 예약어 충돌
- RL Load의 Motor 모델링 한계
- MOSFET Source 저항에 의한 `VGS` 감소
- Gate Resistor 필요성
- Flyback Diode 누락
- Fan 출력이 Thermal Model에 반영되지 않던 Open-loop 구조

최종적으로 이를

```text
Sensor
→ Analog Comparator
→ Pulse Generation
→ Power Switching
→ Load
→ Thermal Feedback
```

의 하나의 시스템으로 통합하였다.

## 11. 본 프로젝트의 의미

이 프로젝트는 단순히
“온도가 높아지면 Fan이 켜지는 회로”를 구현하는 데서 끝나지 않았다.

최종적으로 다음 기술 요소를 하나의 흐름으로 연결하였다.

```text
Temperature Sensor
        ↓
Analog Signal
        ↓
Comparator
        ↓
Hysteresis
        ↓
Pulse/PWM
        ↓
MOSFET Gate
        ↓
Power Switching
        ↓
Fan
        ↓
Thermal Feedback
```

이를 통해

- Analog Sensor Interface
- Comparator Circuit
- Feedback
- Power MOSFET Switching
- Inductive Load Protection
- Thermal Modeling
- LTspice Verification

이 서로 어떻게 연결되는지를 학습하였다.

## 12. Model Limitations

현재 결과는 실제 제품의 정밀 Thermal Simulation이 아니라
**System-level Equivalent Model**에 기반한 결과이다.

따라서 다음 한계가 있다.

- Thermal Parameter `Rth`, `Cth`, `Pheat`, `Pcool`은 단순화된 값
- NTC 공차 및 자기발열 미반영
- MOSFET은 단순 `Level=1` 모델
- 실제 `RDS(on)`, Gate Charge, Switching Loss 미반영
- Fan Model에 Rotor Inertia, Torque, Friction 미포함
- RPM은 실제 회전방정식 결과가 아니라 표시용 신호
- Fan Cooling은 RPM에 연속 비례하지 않고 ON/OFF 방식
- 실제 PCB 기생성분 및 Noise 미반영

따라서 실제 Hardware 제작 단계에서는
Simulation 결과를 그대로 실제 제품 성능으로 해석해서는 안 된다.

---

## 13. 향후 확장 계획

실물 제작 단계에서는 다음 항목을 추가 측정할 수 있다.

- 실제 NTC 45℃ / 50℃ 저항
- Comparator 실제 Switching Temperature
- Fan Starting Voltage / Starting Duty
- 실제 Fan RPM
- MOSFET `VGS`, `VDS`, `IDS`
- MOSFET 온도
- Flyback Voltage Spike
- Fan ON/OFF 시 실제 Temperature Slope

실측 데이터를 이용해

```text
Rth
Cth
Pcool
```

등의 Thermal Parameter를 보정하면
현재 모델을 실제 Hardware에 가까운 Electro-Thermal Model로 발전시킬 수 있다.

---

## 14. 최종 결론

최종 LTspice Simulation을 통해

```text
NTC
→ LT1016
→ NE555
→ NMOS
→ Fan
→ Cooling
→ NTC
```

로 이어지는 Closed-loop 자동 온도 제어 시스템을 구현하였다.

최종 계산 및 Simulation에서

- 약 **49.3℃ Fan ON**
- 약 **45.5℃ Fan OFF**
- 약 **3.8℃ Hysteresis**

를 확인하였다.

또한 Comparator Output, NE555 Output,
MOSFET Gate 및 RPM 신호를 개별적으로 확인하여
각 Block이 순차적으로 연결되는 것을 검증하였다.

이 프로젝트의 최종 성과는 Fan 자체가 아니라,

> **센서 신호 처리부터 Power Semiconductor Switching, Load 구동, Thermal Feedback까지 이어지는 전체 시스템을 LTspice에서 모델링하고 검증한 것**

에 있다.
