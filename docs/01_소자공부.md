# 01. 주요 소자 및 회로 개념

> Project: Automatic Temperature Control Fan  
> Tool: LTspice  
> Focus: Analog Circuit / Power Switching / Sensor Interface

---

## 1. 문서 목적

본 문서는 Automatic Temperature Control Fan 프로젝트의 최종 회로에 실제로 사용한 주요 소자와
각 소자가 시스템 안에서 수행하는 역할을 정리한 문서이다.

초기 설계 단계에서는 가변저항을 이용해 Comparator의 기준전압을 직접 조절하는 방안도 검토하였다.
그러나 최종 회로에서는 가변저항 대신 **R6 10kΩ과 R9 3.9kΩ의 고정 분압회로**를 사용하였고,
R5 68kΩ의 Positive Feedback을 추가하여 약 49.3℃ ON / 45.5℃ OFF의 Hysteresis를 구현하였다.

따라서 이 문서에서는 최종 시뮬레이션 회로를 기준으로 다음 요소를 설명한다.

- NTC Thermistor
- Voltage Divider
- Reference Voltage
- LT1016 Comparator
- Hysteresis
- NE555
- NMOS
- Gate Resistor
- Flyback Diode
- Fan Model
- Thermal Equivalent Model

# 2. NTC Thermistor

## 2.1 NTC란?

NTC는 **Negative Temperature Coefficient Thermistor**의 약자로,
온도가 올라갈수록 저항값이 감소하는 온도 센서이다.

본 프로젝트에서는 열원의 온도를 직접 전기 신호로 읽을 수 없기 때문에
온도에 따라 저항이 달라지는 NTC를 이용하여 온도 정보를 회로 안으로 가져왔다.

동작 관계는 다음과 같다.

```text
온도 상승 → NTC 저항 감소
온도 하강 → NTC 저항 증가
```

---

## 2.2 프로젝트에서 사용한 모델

최종 회로에서는 다음 파라미터를 사용하였다.

```spice
.param Beta=3950
.param R25=10000
```

- `R25 = 10kΩ` : 25℃에서의 NTC 저항
- `Beta = 3950` : 온도에 따른 저항 변화 정도를 결정하는 상수

LTspice에서는 NTC 저항값을 다음과 같이 모델링하였다.

```spice
R=R25*exp(Beta*(1/(V(TEMP_MON)+273.15)-1/298.15))
```

여기서 `TEMP_MON`은 열 모델에서 온도를 나타내는 노드이다.

---

## 2.3 왜 NTC만으로 팬을 바로 켤 수 없는가?

NTC는 온도에 따라 **저항값만 변화**한다.
하지만 Comparator는 두 개의 전압을 비교하는 소자이기 때문에
NTC 저항 변화를 전압 변화로 바꿔주는 과정이 필요하다.

이 때문에 NTC와 고정저항을 이용해 Voltage Divider를 구성하였다.

---

# 3. Voltage Divider

## 3.1 기본 원리

두 저항이 직렬로 연결되어 있을 때 중간 노드의 전압은 저항 비율에 따라 결정된다.

```text
VCC
 │
 R3
 │
 ├── Vsensor
 │
NTC
 │
GND
```

본 프로젝트에서는 R3 10kΩ과 NTC를 사용하였다.

센서전압은 다음과 같이 생각할 수 있다.

```text
Vsensor = VCC × RNTC / (R3 + RNTC)
```

온도가 상승하면 NTC 저항이 감소하므로 센서전압도 감소한다.

```text
온도 ↑
  ↓
RNTC ↓
  ↓
Vsensor ↓
```

이 전압이 LT1016 Comparator의 입력으로 전달된다.

---

# 4. Reference Voltage

Comparator가 센서전압이 높은지 낮은지 판단하려면 비교 기준이 필요하다.

최종 회로에서는 가변저항 대신 다음 두 고정저항을 사용하였다.

- R6 = 10kΩ
- R9 = 3.9kΩ

이 두 저항이 Comparator의 기본 Reference Voltage를 만든다.

단순 분압만 고려하면 기준전압은 대략 다음과 같다.

```text
Vref = 5 × 3.9k / (10k + 3.9k)
     ≈ 1.40V
```

하지만 최종 회로에서는 R5 68kΩ을 통한 Positive Feedback이 있기 때문에
Comparator 출력 상태에 따라 실제 기준전압이 조금씩 바뀐다.

이 변화가 Hysteresis를 만든다.

---

# 5. LT1016 Comparator

## 5.1 Comparator의 역할

Comparator는 두 입력 전압을 비교하여 어느 쪽이 더 큰지 판단하는 소자이다.

기본 동작은 다음과 같다.

```text
V(+) > V(-) → Output HIGH
V(+) < V(-) → Output LOW
```

본 프로젝트에서는

- 한쪽 입력: NTC에서 만들어진 Sensor Voltage
- 다른 입력: R6/R9 및 R5에 의해 만들어지는 Reference Voltage

를 비교하였다.

---

## 5.2 프로젝트에서의 신호 흐름

온도가 상승하면 다음과 같은 변화가 발생한다.

```text
온도 상승
  ↓
NTC 저항 감소
  ↓
Sensor Voltage 감소
  ↓
Comparator 임계조건 만족
  ↓
LT1016 Output 전환
  ↓
NE555 동작 상태 변화
```

즉 LT1016은 **현재 온도가 팬을 켜야 하는 영역인지 판단하는 경계 장치**이다.

---

# 6. Hysteresis

## 6.1 왜 필요한가?

팬을 정확히 한 온도에서만 ON/OFF하도록 만들면
임계점 근처에서 센서값이 조금만 흔들려도 다음과 같은 현상이 생길 수 있다.

```text
ON → OFF → ON → OFF → ...
```

이를 Chattering이라고 한다.

실제 회로에서는 노이즈나 센서 오차가 존재하기 때문에
ON 기준과 OFF 기준을 서로 다르게 설정하는 것이 안정적이다.

---

## 6.2 본 프로젝트의 구현

LT1016 출력의 일부를 R5 68kΩ을 통해 기준전압 노드로 되돌렸다.

이것은 **Positive Feedback**이다.

Comparator 출력 상태에 따라 기준전압이 달라지면서 두 개의 임계온도가 만들어진다.

최종 계산값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| Fan ON | 약 49.3℃ |
| Fan OFF | 약 45.5℃ |
| Hysteresis Width | 약 3.8℃ |

동작은 다음과 같다.

```text
온도 상승
  ↓
49.3℃ 부근
  ↓
FAN ON
  ↓
온도 하강
  ↓
45.5℃ 부근
  ↓
FAN OFF
```

팬이 켜진 직후 바로 꺼지지 않고 충분히 냉각된 뒤 정지하도록 만든 것이 핵심이다.

---

# 7. NE555 Timer

## 7.1 기본 개념

NE555는 Timer, Oscillator, Pulse Generator 등 다양한 용도로 사용할 수 있는 IC이다.

본 프로젝트에서는 MOSFET Gate를 구동하기 위한 PWM/Pulse 신호를 만드는 데 사용하였다.

---

## 7.2 Comparator와의 관계

LT1016은 팬을 동작시켜야 하는 온도 조건을 판단하고,
NE555는 그 판단 결과에 따라 MOSFET을 구동할 펄스 신호를 생성한다.

```text
LT1016
  ↓
NE555
  ↓
PWM/Pulse
  ↓
NMOS Gate
```

이렇게 역할을 나누면 Comparator가 직접 부하 전류를 처리하지 않고
신호 처리와 전력 구동 단계를 분리할 수 있다.

---

# 8. NMOS

## 8.1 MOSFET을 사용한 이유

팬은 Comparator나 NE555 출력 핀에서 직접 공급하기에는 상대적으로 큰 전류가 필요한 부하이다.

따라서 제어회로는 작은 전압 신호만 만들고,
실제 Fan 전류는 MOSFET이 스위칭하도록 구성하였다.

본 프로젝트에서는 NMOS를 **Low-side Switch**로 사용하였다.

```text
VCC
 │
Fan
 │
Drain
NMOS
Source
 │
GND
```

Gate에 충분한 전압이 들어오면 Drain-Source 경로가 도통되어 팬 전류가 흐른다.

---

## 8.2 VGS

MOSFET에서 가장 중요한 값 중 하나는 `VGS`이다.

```text
VGS = VGate - VSource
```

Gate 전압 자체가 아니라 **Gate와 Source 사이의 전압차**가 중요하다.

프로젝트 시행착오 과정에서 Source와 GND 사이에 큰 저항을 넣으면
전류에 의해 Source 전압이 상승하고, 결과적으로 VGS가 감소하여
MOSFET이 충분히 ON되지 않을 수 있음을 확인하였다.

---

## 8.3 RDS(on)

MOSFET이 충분히 ON되었을 때 Drain과 Source 사이에는 작은 저항이 남는다.
이를 `RDS(on)`이라고 한다.

MOSFET의 도통 손실은 대략 다음 관계로 이해할 수 있다.

```text
Pconduction ≈ IDS² × RDS(on)
```

실제 전력회로에서는 MOSFET 선택 시 중요한 항목이다.

본 프로젝트의 NMOS는 학습용 단순 모델을 사용하였기 때문에
실제 제품 선정 단계에서는 실제 MOSFET 데이터시트를 이용한 추가 검토가 필요하다.

---

# 9. Gate Resistor

최종 회로에서는 NE555 출력과 MOSFET Gate 사이에 R2 100Ω을 사용하였다.

MOSFET Gate는 이상적인 무한대 저항 입력이 아니라
내부적으로 Capacitance를 가진다.

따라서 Gate 전압이 변하는 순간 충·방전 전류가 흐른다.

Gate Resistor는 이 순간 전류를 제한하고
Gate 구동의 과도한 Ringing을 완화하는 데 도움을 준다.

```text
NE555 → R2 100Ω → MOSFET Gate
```

저항값이 너무 크면 Gate 충·방전 속도가 느려져 Switching Loss가 증가할 수 있고,
너무 작으면 Driver의 순간 전류가 커질 수 있다.

---

# 10. Flyback Diode

## 10.1 왜 필요한가?

Fan Motor의 권선은 Inductive Load이다.

인덕터에는 다음 특성이 있다.

> 흐르던 전류가 갑자기 0으로 변하는 것을 방해한다.

MOSFET이 OFF되는 순간에도 Motor 권선은 기존 전류를 계속 흐르게 하려 하므로
높은 역전압이 발생할 수 있다.

이를 Back EMF라고 부른다.

---

## 10.2 프로젝트에서 사용한 소자

최종 회로에서는 D3에 **1N5819 Schottky Diode**를 사용하였다.

Flyback Diode는 MOSFET이 OFF될 때
인덕터 전류가 흐를 수 있는 우회 경로를 만들어
Drain에 큰 전압 Spike가 발생하는 것을 억제한다.

```text
MOSFET OFF
   ↓
Motor Current가 계속 흐르려고 함
   ↓
Back EMF 발생
   ↓
Flyback Diode를 통해 전류 순환
   ↓
MOSFET 보호
```

---

# 11. Fan Macro Model

초기에는 Fan을 단순한 RL Load로 표현하였다.

RL 모델은 다음 내용은 확인할 수 있다.

- 부하 전류
- 인덕터 전류의 변화
- MOSFET Switching 여부

하지만 실제 Motor에서 중요한

- 회전속도
- Back EMF
- 기동 특성
- 관성
- 부하에 따른 속도 변화

등을 충분히 표현하기 어렵다.

따라서 최종 단계에서는 `FAN5V.lib` Macro Model을 사용하고
RPM 신호를 열 모델의 Cooling 조건으로 다시 사용하였다.

```text
MOSFET
  ↓
Fan Model
  ↓
RPM Signal
  ↓
Thermal Model
```

이 연결을 통해 전기회로의 출력이 다시 열 모델에 영향을 주는 폐루프를 구성하였다.

---

# 12. Thermal Equivalent Model

## 12.1 왜 열을 회로로 표현하는가?

LTspice는 기본적으로 전기회로 해석기이다.
따라서 온도를 직접 회로 요소로 다루는 대신
열 시스템을 전기회로와 대응시켜 표현하였다.

본 프로젝트에서는 다음 관계를 사용하였다.

```text
TEMP_MON 1V = 1℃
```

---

## 12.2 사용 파라미터

```spice
.param Tamb=25
.param Rth=5
.param Cth=0.5
.param Pheat=6
.param Pcool=15
```

- `Tamb` : 주변 온도
- `Rth` : Thermal Resistance에 대응
- `Cth` : Thermal Capacitance에 대응
- `Pheat` : 지속적인 발열
- `Pcool` : 팬이 동작할 때 적용되는 냉각량

팬이 정지하면 열원 온도가 상승하고,
RPM 신호가 활성화되면 냉각항이 추가되어 온도가 감소한다.

---

# 13. 소자들이 하나의 시스템으로 연결되는 과정

각 소자는 개별적으로 동작하는 것이 아니라 다음과 같은 하나의 신호 체인을 구성한다.

```text
Thermal Model
      ↓
NTC Thermistor
      ↓
Voltage Divider
      ↓
LT1016 Comparator
      ↓
Hysteresis
      ↓
NE555
      ↓
Gate Resistor
      ↓
NMOS
      ↓
Fan + Flyback Diode
      ↓
RPM
      ↓
Thermal Model Feedback
```

이 프로젝트를 통해 단순히 각 소자의 정의를 암기하는 것보다
**센서 → 아날로그 판단 → 제어 신호 → 전력 스위칭 → 부하 → 피드백**
으로 이어지는 전체 시스템 관점에서 회로를 이해하는 것이 중요하다는 점을 학습하였다.

# 14. 프로젝트에서 특히 중요했던 개념

| 개념 | 프로젝트에서의 의미 |
|---|---|
| NTC | 온도를 저항 변화로 변환 |
| Voltage Divider | 저항 변화를 전압으로 변환 |
| Reference Voltage | 팬 동작 기준 생성 |
| Comparator | 현재 온도와 기준값 비교 |
| Hysteresis | ON/OFF 기준을 분리하여 Chattering 방지 |
| NE555 | MOSFET 구동용 Pulse 생성 |
| VGS | NMOS가 제대로 ON되는지 판단하는 핵심 전압 |
| Gate Charge | MOSFET Gate 구동 속도와 관련 |
| RDS(on) | MOSFET 도통손실과 관련 |
| Back EMF | 유도성 부하 OFF 시 발생하는 역전압 |
| Flyback Diode | Back EMF로부터 MOSFET 보호 |
| Thermal Feedback | 팬 동작 결과를 다시 온도 모델에 반영 |

# 15. 정리

최종 회로에서 각 블록의 역할을 한 문장으로 정리하면 다음과 같다.

> NTC가 온도를 감지하고, Voltage Divider가 이를 전압으로 바꾸며, LT1016이 기준전압과 비교한다. Hysteresis는 안정적인 ON/OFF 범위를 만들고, NE555와 NMOS가 팬을 구동한다. Flyback Diode는 유도성 부하의 역기전력으로부터 MOSFET을 보호하며, Fan의 RPM 신호는 다시 Thermal Model의 냉각량에 반영된다.

이 구조를 통해 Analog Circuit, Sensor Interface, Power Switching,
Thermal Modeling 및 Feedback Control이 하나의 시스템 안에서 어떻게 연결되는지 학습하였다.
