# 1. 개요

이번 프로젝트에서는 가변저항(Potentiometer)을 단순히 저항값을 조절하는 부품이 아니라, **온도 제어 시스템의 기준 전압(Reference Voltage)을 생성하는 핵심 소자**로 사용하였다.

처음에는 NTC Thermistor의 저항 변화만으로 팬의 동작을 제어할 수 있다고 생각하였다. 그러나 실제 회로를 설계하면서 Comparator는 두 입력 전압을 비교하는 소자이므로 반드시 비교 기준이 되는 기준전압이 필요하다는 점을 알게 되었다.

따라서 본 프로젝트에서는 가변저항을 이용하여 기준전압을 생성하고, NTC Thermistor에서 생성되는 센서 전압과 비교함으로써 특정 온도 이상에서만 팬이 동작하도록 설계하였다.

즉, 가변저항은 팬이 몇 ℃에서 동작할 것인지를 결정하는 가장 중요한 조정 장치라고 볼 수 있다.

---

# 2. Potentiometer의 정의

Potentiometer는 저항체 위를 금속 접점(Wiper)이 이동하면서 저항값을 연속적으로 변화시키는 수동소자(Passive Component)이다.

일반 저항은 제작 후 저항값이 고정되지만, Potentiometer는 사용자가 원하는 위치로 Wiper를 이동하여 출력 전압 또는 저항을 자유롭게 조절할 수 있다.

전자회로에서는 다음과 같은 용도로 가장 많이 사용된다.

- 기준전압 생성
- 전압분배기
- 센서 보정(Calibration)
- 증폭기 Gain 조절
- PWM Duty 조절
- LCD 명암 조절
- 기준 온도 설정
- 산업용 장비 초기 Calibration

본 프로젝트에서는 Comparator가 비교할 기준전압을 생성하는 역할로 사용하였다.

# 3. 내부 구조

Potentiometer는 크게 세 부분으로 구성된다.

① Resistive Element (저항체)

탄소(Carbon), Cermet, Metal Film 등으로 만들어진 일정한 저항체이다.

양 끝단 사이의 저항값은 항상 일정하다.

예를 들어 10kΩ Potentiometer라면

A -----10kΩ----- B

항상 A-B 사이의 저항은 10kΩ이다.

---

② Wiper

가운데 단자이다.

손잡이를 돌리면 Wiper가 이동하면서

A와 Wiper 사이 저항

Wiper와 B 사이 저항

이 서로 반대로 변한다.

예를 들어

10kΩ Pot

왼쪽 끝

A-W =0Ω

W-B =10kΩ

중앙

A-W =5kΩ

W-B =5kΩ

오른쪽 끝

A-W =10kΩ

W-B =0Ω

이처럼 전체 저항은 변하지 않지만 분배 비율만 달라진다.

---

③ Shaft

사용자가 직접 돌리는 축이다.

회전형

슬라이드형

멀티턴형

등 여러 종류가 존재한다.

실제 산업에서는 미세한 조정을 위해 10Turn Potentiometer를 많이 사용한다.

두 저항이 직렬 연결되었을 때 출력 전압은 저항 비율에 따라 결정된다.

# 5. 프로젝트에서 수행한 역할

본 프로젝트는 일정 온도 이상에서 팬이 자동으로 동작하는 회로이다.

NTC Thermistor는 온도가 상승하면 저항이 감소한다.

저항이 감소하면 전압분배 결과 출력전압도 변화하게 된다.

하지만 Comparator는 기준이 없으면 아무 것도 판단하지 못한다.

따라서 Potentiometer를 이용하여

예를 들어

2.8V

라는 기준전압을 만들고

NTC 출력이

2.8V보다 높아지는 순간

Comparator 출력이 HIGH가 된다.

HIGH 출력은 MOSFET Gate로 전달된다.

MOSFET이 ON된다.

팬이 회전한다.

즉

온도 설정 기능

을 Potentiometer가 담당한다.

온도센서보다도 중요한 이유가 여기에 있다.

# 6. LTspice에서 사용한 이유

LTspice에는 기본 Potentiometer 부품이 존재하지 않는다.

따라서 두 개의 저항을 직렬 연결하거나 Parameter를 이용하여 Potentiometer를 구현한다.

예)

Rtop

Rbottom

Ratio

Parameter

등을 사용하여 실제 가변저항과 동일하게 모델링하였다.

실제 회로에서는 10kΩ B타입 Potentiometer를 가장 많이 사용한다.

본 프로젝트 역시 동일한 개념으로 기준전압을 생성하였다.
