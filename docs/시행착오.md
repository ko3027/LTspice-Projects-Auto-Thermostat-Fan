⚡ 시행착오 01. 만약 팬 작동 온도가 ntc 저항 기준 49도 라고 했을 때 팬의 작동 여부

📌 프로젝트 상황

저항값이 49도에서 팬이 돌아가게 작동하여 만들었다.

활용 용도에 따라 특정 온도를 정하고 작동하게 설계하였다.

📌 발생한 문제

정해진 온도에 팬이 돌아간다 치자.
예를 들어서 49도에서 팬이 돌아간다 설계하면 49.1도에는 안 돌아가는 현상 발생

📌 원인 분석

일정 온도에서 돌아가는 방식이 아닌 온도 범위를 정하고 그 안에서 돌아가게 설계를 한다. 이를 해결하기 위해 비교기 입력에 저항이라느 피드백을 걸어 on off 기준을 다르게 하는 방식을 이용.

📌 결과
컴퓨터에 사용하는 cpu 쿨러를 만든다는 가정하에 50도 이상이면 팬이 작동하게 설계하였지만 비교기에 저항을 추가해 49~50 사이에도 온도에 팬이 돌아가게 설계.





⚡ 시행착오 02. LTspice 예약어 사용으로 시뮬레이션이 시작되지 않은 문제
📌 프로젝트 상황

온도 변화에 따라 NTC 저항값을 계산하기 위해 온도를 파라미터로 정의하였다.

.param Temp=25
.param Beta=3950
.param R25=10000
.param TK={Temp+273.15}
.param RNTC={R25*exp(Beta*(1/TK-1/298.15))}

온도를 변경하면서 비교기의 동작점을 확인하고자 하였다.

📌 발생한 문제

시뮬레이션을 실행하자 다음과 같은 오류가 발생하였다.

Invalid parameter name.
"temp" is a reserved symbol for temperature.
Use ".temp" to set temperature.

회로 자체를 해석하기 전에 시뮬레이션이 종료되었으며, 이후 단계의 회로 동작은 확인할 수 없었다.

📌 원인 분석

처음에는 NTC 계산식의 오류를 의심하였다.

그러나 오류 내용을 분석한 결과 문제는 계산식이 아니라 변수 이름이었다.

LTspice에서는 temp가 시뮬레이션 온도를 제어하는 내부 예약어로 이미 사용되고 있다.

따라서

.param Temp=25

를 사용자 정의 변수로 선언하면 LTspice Parser가 예약어와 충돌을 감지하고 시뮬레이션을 중단한다.

즉,

문제가 된 것은 계산식이 아니라 예약어와 사용자 변수명의 충돌이었다.

📌 해결 방법

예약어와 겹치지 않는 이름으로 변경하였다.

수정 전

.param Temp=25
.param TK={Temp+273.15}

수정 후

.param Tset=25
.param TK={Tset+273.15}

관련 계산식도 모두 동일하게 변경하였다.

📌 결과

예약어 충돌이 제거되어 LTspice가 정상적으로 Netlist를 생성할 수 있는 상태가 되었다.

이후부터는 실제 회로 연결 상태와 비교기, NE555, MOSFET의 동작을 순차적으로 검증할 수 있었다.

📌 이번 시행착오를 통해 배운 점

회로 설계에서는 부품 연결만큼 시뮬레이터의 문법과 예약어 체계도 중요하다는 것을 알게 되었다.

특히 프로젝트 규모가 커질수록 변수명을 명확하게 관리하는 습관이 디버깅 시간을 크게 줄여준다는 점을 경험하였다.

초기에는 전류를 제한하거나 회로를 안정화할 수 있을 것이라 생각하였다.


🔍 원인 분석

N채널 MOSFET은

Gate와 Source의 전압차(VGS)

가 충분해야 완전히 ON 된다.

하지만 Source에 저항을 삽입하면

전류가 흐르는 순간

Source 전압 상승

↓

VGS 감소

↓

MOSFET이 완전히 ON되지 않음

이라는 현상이 발생한다.

즉, MOSFET이 스위치처럼 동작하지 못하고 선형 영역에서 동작할 가능성이 커진다.


🛠 해결 방향

Source는 GND와 직접 연결하고,

필요한 경우 전류 측정을 위한 매우 작은 Shunt 저항(예: 0.1Ω 이하)을 사용하는 것이 일반적이다.

현재 사용한 220Ω은 너무 큰 값이므로  노이즈 제거용인 100u Ω 으로 수정할 예정이다.

✅ 예상 결과

MOSFET이 완전히 포화 영역에서 동작하여 부하에 충분한 전류를 공급할 수 있다.

스위칭 손실도 감소할 것으로 예상된다.

💡 배운 점

MOSFET은 단순히 전압을 인가한다고 동작하는 것이 아니라

Gate-Source 전압이 가장 중요한 요소라는 점을 이해하였다.

Source 저항은 특별한 목적이 없는 한 사용하지 않는 것이 일반적이라는 점도 함께 학습하였다.

는 필요 없습니다.

현재 목표 회로는:

비교기와 센서: 5V
팬: 12V

두 전원만 있으면 됩니다.

따라서 V3 8V는 삭제하세요.

LTspice에서 V3를 클릭한 뒤 Delete 키를 누르면 됩니다.

남길 전원:

V2 = 5V
V4 = 12V

V1 12V도 별도로 존재하므로 V1과 V4 중 하나만 사용하세요.

즉 전원은 총 두 개로 정리합니다.

VCTRL = 5V
VFAN  = 12V

그리고 두 전원의 마이너스는 모두 같은 GND로 연결해야 합니다.
